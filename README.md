# Smart Pantry Manager

## Overview

Smart Pantry Manager is an Android application developed in Java that helps users manage pantry ingredients and find recipes based on the ingredients available.

## Features

* **Add Ingredients:** Add ingredients with their quantities and units.
* **View Pantry:** Display ingredients stored in the pantry.
* **Edit and Delete:** Update or remove pantry ingredients.
* **Recipe Suggestions:** Find recipes that match available ingredients and required quantities.
* **Recipe Details:** View recipe ingredients and preparation instructions.
* **Settings:** Access the application's settings screen.
* **Data Persistence:** Store pantry and recipe data locally using SQLite.

## Installation and Setup

1. Clone or download this repository.
2. Open Android Studio.
3. Select **Open** and choose the project folder.
4. Allow Gradle to sync.
5. Run the application using an Android emulator or compatible Android device.

## Purpose

This project demonstrates Android development, SQLite database integration, CRUD operations, input validation, screen navigation using Intents, and version control with Git.
